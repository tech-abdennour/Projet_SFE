## 🎯 Présentation

**VALA BLEU** est une application web complète qui prédit la **charge serveur** d'un site WordPress en fonction de **20 paramètres** (trafic, ressources, configuration). L'outil utilise un modèle **XGBoost** entraîné sur 100 000 échantillons synthétiques.

### Fonctionnalités Principales

- 🔐 Authentification multi-utilisateurs
- ⚙️ Saisie de 20 paramètres WordPress
- 🤖 Prédiction XGBoost via API REST
- 💾 Sauvegarde des analyses en historique
- 🗑️ Corbeille avec restauration
- 📊 6 graphiques d'analyse du modèle
- 📥 Export CSV et JSON
- 👤 Isolation des données par utilisateur

## 🚀 Installation

### Prérequis

- **PHP 8.0+** avec extensions : `sqlite3`, `curl`, `json`
- **Python 3.10+** avec packages :
  ```bash
  pip install xgboost scikit-learn pandas numpy joblib fastapi uvicorn matplotlib seaborn
  ```
- **Serveur web** : Apache/Nginx OU serveur PHP intégré
- **Port 8000** disponible pour l'API Python

### Étapes d'Installation

#### 1. Cloner le projet
```bash
git clone https://github.com/votre-repo/vala-bleu.git
cd vala-bleu
```

#### 2. Configurer la racine web
```bash
# Option A : Serveur PHP intégré
cd /var/www/html
php -S localhost:80

# Option B : Apache/Nginx
# Pointer le DocumentRoot vers /var/www/html
```

#### 3. Créer les dossiers backend
```bash
mkdir -p /app/service/models
mkdir -p /app/service/graphe
mkdir -p /app/service/data
```

#### 4. Entraîner le modèle XGBoost
```bash
cd /app/service
python3 train_xgboost_model.py
# Vérifier : ls -lh /app/service/models/model.pkl
```

#### 5. Lancer l'API Python
```bash
cd /app/service
python3 api_server.py
# Écoute sur http://localhost:8000
```

#### 6. Vérifier l'installation
```bash
# API en ligne ?
curl http://localhost:8000/health

# Application web ?
curl http://localhost/index.php
```

### 2. Dashboard (6 onglets)

| Onglet | Icône | Fonction |
|--------|-------|----------|
| **Paramètres** | ⚙️ | Saisie des 20 paramètres WordPress |
| **Résultats** | 📊 | Prédictions XGBoost + score |
| **Sauvegardes** | 💾 | Sauvegarde JSON + historique |
| **Historique** | 📋 | Liste des analyses passées |
| **Corbeille** | 🗑️ | Analyses archivées (restaurer/supprimer) |
| **Graphiques** | 📈 | 6 visualisations du modèle (🆕) |

### 3. Paramètres à saisir

#### 📈 Trafic (4 paramètres)
- Visiteurs/jour * (50 - 150 000)
- Pages vues/jour
- Taux de croissance (%) * (0 - 85%)
- Pics horaires (début/fin)

#### 🖥️ Ressources Serveur (8 paramètres)
- CPU moyen * (5 - 100%)
- CPU max * (8 - 100%)
- RAM moyenne * (8 - 100%)
- RAM max * (12 - 100%)
- Disque occupé (%) (5 - 96%)
- Disque max / bande passante (%) (8 - 100%)
- IOPS Read (1 - 3500)
- IOPS Write (1 - 2800)
- Temps de réponse (ms)

#### 🔌 WordPress (8 paramètres)
- Nombre de plugins * (1 - 80)
- Plugins lourds (7 cases à cocher)
- Version PHP
- Cache activé (oui/non)
- CDN activé (oui/non)
- Pack WordPress * (SMALL/MEDIUM/PERFORMANCE)

*\* Champs obligatoires*

### 4. Résultats de Prédiction

Après analyse, l'API retourne :

| Champ | Description | Exemple |
|-------|-------------|---------|
| `xgboost_score` | Score de confiance (%) | 78.5% |
| `predicted_load` | Charge prédite (%) | 72.3% |
| `saturation_months` | Mois avant saturation | 6 mois |
| `status` | Statut global | SURVEILLANCE |
| `recommendation` | Conseil textuel | "Activer le cache..." |

**Codes statut :**
- 🟢 **OPTIMAL** : Charge < 50%
- 🟡 **SURVEILLANCE** : Charge 50-75%
- 🔴 **CRITIQUE** : Charge > 75%

## 🗄️ Base de Données

**SGBD :** SQLite 3  
**Fichier :** `/var/www/html/vala_bleu.db`

### Tables

#### 1. `predictions` (Historique des analyses)

| Colonne | Type | Description |
|---------|------|-------------|
| `id` | INTEGER PK | Identifiant unique |
| `user` | TEXT | Nom d'utilisateur |
| `created_at` | DATETIME | Date de création |
| `visitors_per_day` | INTEGER | Visiteurs/jour |
| `cpu_usage_avg` | REAL | CPU moyen |
| `wp_type` | TEXT | Type WordPress |
| `predicted_load` | REAL | Charge prédite |
| `xgboost_score` | REAL | Score XGBoost |
| `status` | TEXT | Statut (CRITIQUE/SURVEILLANCE/OPTIMAL) |
| `recommendation` | TEXT | Recommandation |
| `is_deleted` | INTEGER | 0=actif, 1=corbeille |

#### 2. `deleted_sauvegardes` (Corbeille)

| Colonne | Type | Description |
|---------|------|-------------|
| *(mêmes colonnes que predictions)* | | |
| `deleted_at` | DATETIME | Date d'archivage |

#### 3. `saved_results` (Sauvegardes JSON)

| Colonne | Type | Description |
|---------|------|-------------|
| `id` | INTEGER PK | Identifiant |
| `created_at` | DATETIME | Date de sauvegarde |
| `data_json` | TEXT | Données au format JSON |
| `save_type` | TEXT | Type de sauvegarde |

### Requêtes types

```sql
-- Analyses d'un utilisateur
SELECT * FROM predictions WHERE user = 'admin' AND is_deleted = 0;

-- Corbeille d'un utilisateur
SELECT * FROM deleted_sauvegardes WHERE user = 'Ahmed';

-- Vider la corbeille
DELETE FROM deleted_sauvegardes WHERE user = 'admin';
```

## 🤖 Modèle XGBoost

### Caractéristiques

| Paramètre | Valeur |
|-----------|--------|
| **Algorithme** | XGBoost Regressor |
| **Objectif** | Regression (squarederror) |
| **Arbres** | 450 estimateurs |
| **Profondeur max** | 5 |
| **Learning rate** | 0.045 |
| **Subsample** | 0.9 |
| **Colsample** | 0.9 |
| **Échantillons** | 100 000 |
| **Split train/test** | 80% / 20% |
| **Random state** | 42 |

### Top 10 Features (Importance)

| Rang | Feature | Impact | Description |
|------|---------|--------|-------------|
| 1 | `visitors_per_day` | ⭐⭐⭐⭐⭐ | Trafic quotidien |
| 2 | `cpu_usage_avg` | ⭐⭐⭐⭐⭐ | Charge CPU moyenne |
| 3 | `ram_usage_avg` | ⭐⭐⭐⭐⭐ | RAM utilisée |
| 4 | `wp_type` | ⭐⭐⭐⭐ | Type de pack |
| 5 | `traffic_growth_rate` | ⭐⭐⭐⭐ | Croissance trafic |
| 6 | `cpu_usage_peak` | ⭐⭐⭐⭐ | Pic CPU |
| 7 | `plugin_count` | ⭐⭐⭐⭐ | Nombre de plugins |
| 8 | `ram_usage_max` | ⭐⭐⭐⭐ | Pic RAM |
| 9 | `heavy_plugins` | ⭐⭐⭐⭐ | Plugins lourds |
| 10 | `cache_enabled` | ⭐⭐⭐⭐ | Cache activé |

### Métriques de Performance

| Métrique | Valeur cible | Description |
|----------|--------------|-------------|
| **R²** | > 0.90 | Coefficient de détermination |
| **RMSE** | < 3.0 | Racine erreur quadratique |
| **MAE** | < 2.5 | Erreur absolue moyenne |
| **Accuracy** | > 85% | Précision relative |

### Contenu du model.pkl

```python
{
    "model": XGBRegressor(),           # Modèle entraîné
    "feature_columns": [...],          # 20 colonnes features
    "target_column": "recommended_capacity_score",
    "heavy_plugin_options": [...],     # 7 plugins lourds
    "categorical_options": {...},      # PHP, cache, CDN, wp_type
    "impact_reference": {...},         # Importance des features
    "performance_metrics": {           # ⭐ Métriques calculées
        "r2": 0.95,
        "rmse": 2.34,
        "mae": 1.87,
        "accuracy": 89.5
    },
    "metadata": {...}                  # Timestamp, paramètres
}
```

## 🌐 API Backend

### Endpoints

| Méthode | URL | Description |
|---------|-----|-------------|
| **GET** | `/health` | Vérification service |
| **POST** | `/predict/from-file` | Prédiction depuis JSON |
| **GET** | `/download/tree0` | Télécharger arbre n°0 |
| **GET** | `/download/tree-final` | Télécharger dernier arbre |
| **GET** | `/download/feature-importance` | Télécharger importance |
| **GET** | `/download/residuals` | Télécharger résidus |
| **GET** | `/download/correlation` | Télécharger corrélation |
| **GET** | `/download/learning-curve` | Télécharger courbe apprentissage |

### Exemple de Requête

```bash
curl -X POST http://localhost:8000/predict/from-file \
  -H "Content-Type: application/json" \
  -d '{
    "visitors_per_day": 50000,
    "cpu_usage_avg": 72.5,
    "ram_usage_avg": 68.3,
    "wp_type": "medium",
    "php_version": "8.2",
    "cache_enabled": "oui",
    "cdn_enabled": "non",
    "plugin_count": 25,
    "traffic_growth_rate": 15.0
  }'
```

### Exemple de Réponse

```json
{
  "xgboost_score": 78.5,
  "predicted_load": 72.3,
  "saturation_months": 6,
  "status": "SURVEILLANCE",
  "recommendation": "Activer le cache et migrer vers PHP 8.3. Réduire les plugins lourds.",
  "graphs": {
    "tree_0": "/download/tree0",
    "tree_final": "/download/tree-final",
    "feature_importance": "/download/feature-importance"
  }
}

## 🔧 Dépannage

### Problèmes Courants

#### 1. L'API ne répond pas
```bash
# Vérifier que l'API tourne
ps aux | grep api_server.py
curl http://localhost:8000/health

# Redémarrer l'API
cd /app/service && python3 api_server.py &
```

#### 2. Le modèle ne se charge pas
```bash
# Vérifier que model.pkl existe
ls -lh /app/service/models/model.pkl

# Régénérer le modèle
python3 /app/service/train_xgboost_model.py
```

#### 3. Graphiques manquants
```bash
# Vérifier le dossier
ls -la /app/service/graphe/

# Régénérer les graphiques
python3 -c "from train_xgboost_model import train_model; train_model()"
```

#### 4. Erreur SQLite
```bash
# Vérifier les permissions
ls -la /var/www/html/vala_bleu.db
chmod 666 /var/www/html/vala_bleu.db
```

#### 5. Session PHP non persistante
```php
// Vérifier la configuration PHP
php -i | grep session.save_path
// Doit être accessible en écriture
```

## 🎓 Glossaire

| Terme | Définition |
|-------|------------|
| **XGBoost** | Algorithme de Machine Learning par gradient boosting |
| **R²** | Coefficient de détermination (qualité de prédiction) |
| **RMSE** | Root Mean Squared Error (erreur quadratique moyenne) |
| **MAE** | Mean Absolute Error (erreur absolue moyenne) |
| **IOPS** | Input/Output Operations Per Second (disque) |
| **Feature** | Paramètre d'entrée du modèle |
| **Target** | Valeur à prédire (charge serveur) |
| **Overfitting** | Surapprentissage (modèle trop complexe) |
