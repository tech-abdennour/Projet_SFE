Voici les liens que tu peux ouvrir dans ton navigateur pour accéder à ton application (en local) :

- Interface principale :  
  [http://localhost:8080/](http://localhost:8080/)

- Dashboard (si dashboard.php est la page d’accueil) :  
  [http://localhost:8080/app/dashboard.php](http://localhost:8080/app/dashboard.php)

- Page d’accueil (index.php) :  
  [http://localhost:8080/app/index.php](http://localhost:8080/app/index.php)

- API Python (FastAPI docs, si exposé) :  
  [http://localhost:8000/docs](http://localhost:8000/docs)

- API prédiction (endpoint direct) :  
  [http://localhost:8000/predict/from-file](http://localhost:8000/predict/from-file)

Adapte le port si tu as changé la configuration dans docker-compose.yml.  
Dis-moi si tu veux les liens pour d’autres pages ou endpoints spécifiques !
